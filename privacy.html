그림셈(DrawCalc) 개인정보처리방침

시행일: 2026년 9월 29일

그림셈(DrawCalc, 이하 "앱")은 초등학생과 학부모, 교사를 위한 수학 학습 도구입니다. 앱은 사용자의 이름, 연락처, 위치, 사진, 기기 식별 번호 같은 개인정보를 모으지 않습니다.

1. 모으는 정보

앱은 사용자가 설정 → 의견 보내기에서 보내기 단추를 누를 때만 아래 내용을 개발자에게 보냅니다.

항목 설명
별점, 의견 종류 사용자가 고른 값
쓴 사람 학생 / 선생님 / 학부모 / 그 밖에 중 사용자가 고른 값 (이름은 받지 않음)
하고 싶은 말 사용자가 직접 쓴 글 (최대 1000자)
지금 넣은 식 사용자가 "함께 보내기"를 켠 경우만
앱 정보 학년, 그림 모양, 언어, 앱 버전, 웹/앱 구분, 화면 크기

의견 보내기 화면에서 "이름, 전화번호, 주소처럼 나를 알 수 있는 내용은 쓰지 마세요"라고 안내합니다.

2. 쓰는 곳

보내 준 의견은 앱을 고치고 더 좋게 만드는 데에만 씁니다. 광고, 판매, 다른 목적에는 쓰지 않습니다.

3. 보관과 삭제

  • 의견은 개발자의 구글 계정(구글 스프레드시트)에 보관합니다.
  • 앱을 고치는 데 더 필요하지 않으면 지웁니다.
  • 보낸 의견을 지워 달라고 요청하시면 지웁니다(아래 연락처).

4. 다른 곳에 주는 정보

받은 의견을 다른 사람이나 회사에 주지 않습니다. 의견을 받고 보관하는 데 구글(Google Apps Script, 구글 스프레드시트)을 사용합니다.

5. 기기 안에만 저장하는 것

학년, 언어, 그림 모양, 선생님 캐릭터, 화면 모드, 화면 폭 같은 설정은 사용자의 기기(브라우저) 안에만 저장합니다. 개발자에게 보내지 않습니다. 앱이나 브라우저 데이터를 지우면 함께 지워집니다.

6. 광고·분석·권한

  • 광고가 없습니다.
  • 사용 기록을 모으는 분석 도구가 없습니다.
  • 카메라, 마이크, 위치, 연락처 같은 기기 권한을 요청하지 않습니다.

7. 어린이

앱은 어린이가 쓰는 것을 전제로 만들었습니다. 어린이의 개인정보를 모으지 않으며, 의견 보내기에도 이름과 연락처를 받지 않습니다.

8. 바뀌는 경우

이 방침이 바뀌면 이 페이지에 알리고 시행일을 고칩니다.

DrawCalc Privacy Policy

Effective date: September 29, 2026

DrawCalc ("the app") is a math learning tool for elementary school students, parents and teachers. The app does not collect users' personal information such as names, contact details, location, photos or device identifiers.

What is sent, and when: only when the user presses Send in Settings → Feedback, the app sends the rating, feedback type, who is writing (student / teacher / parent / other — no names), the message the user typed (up to 1,000 characters), the current expression (only if the user chooses to include it), and app information (grade, picture model, language, app version, web/app, screen size). The feedback screen asks users not to write anything that identifies them.

Use: feedback is used only to fix and improve the app — never for advertising or sale.

Storage and deletion: feedback is stored in the developer's Google account (Google Sheets) and deleted when no longer needed, or on request.

Sharing: feedback is not shared with anyone. Google Apps Script and Google Sheets are used to receive and store it.

On-device settings: settings such as grade, language, picture model, teacher character, screen mode and panel width are stored only on the user's device and are never sent to the developer.

Ads, analytics, permissions: no ads, no analytics, and no device permissions (camera, microphone, location, contacts) are requested.

Children: the app is designed for children. It does not collect children's personal information.

Changes: changes will be posted on this page with a new effective date.
